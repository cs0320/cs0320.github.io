# CSCI 0320/1340 Website

To update lectures, etc. change `src/data/*.json`. 

## Scripts 

* `npm start` to run in development mode. 
* `npm build` will also run typechecking and tests that the lectures, assignments, etc. data files conform to the refinements that typechecking can't fully validate. If tests fail, the build will stop. 

## Deployment 

The site automatically deploys to Github pages on a push.
